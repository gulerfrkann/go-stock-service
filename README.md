# Go Stock Service REST API

Go (Golang) ve Fiber framework kullanılarak geliştirilmiş, yüksek performanslı ve hafif bir **Stok Yönetim Mikroservisi** REST API projesi.

Proje; ürün listeleme, yeni ürün ekleme ve sipariş durumlarında stok düşme gibi temel envanter operasyonlarını yönetir.

---

##  Teknolojiler ve Kütüphaneler

* **Dil:** Go (Golang)
* **Web Framework:** [Fiber v2](https://gofiber.io/) (Express.js ilhamlı, yüksek performanslı Go web framework'ü)
* **Mimari:** RESTful API Architecture
* **Sürüm Kontrolü:** Git & GitHub

---
